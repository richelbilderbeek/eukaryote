# Eukaryote

Eukaryote is one of [Richèl Bilderbeek's games](https://richelbilderbeek.github.io/games/).

Eukaryote is a top-view strategy game in which the units are cells and organelles.

Check out the presentation: [odp](https://github.com/richelbilderbeek/Eukaryote/blob/master/GameEukaryote.odp), [ppt](https://github.com/richelbilderbeek/Eukaryote/blob/master/GameEukaryote.ppt).
